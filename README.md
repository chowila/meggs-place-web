# Megg's Place Kisumu – Web Platform

Official website for **Megg's Place Kisumu** ([meggsplace.com](https://meggsplace.com/)), designed for independent, direct guest bookings without relying on third-party online travel agencies (OTAs) or middleman commissions.

---

## 🌟 Overview & Core Ethos

* **Brand Tagline:** Luxury, Thrift, Creativity on a Budget.
* **Property Type:** Executive Apartment Hotel & Business Suites.
* **Location:** Kisumu, Kenya (Kisumu - Kakamega Highway).
* **Direct Booking Guarantee:** Eliminates 15%–20% third-party OTA commission markups. Guests book directly via WhatsApp, Phone (`+254 722 210 190`), or direct inquiry form.
* **Accepted Payments:** Safaricom M-PESA and Cash only.

---

## 🏨 Featured Room Categories

1. **Mini Studio (1 Guest):** Tailored for solo business travelers and consultants. Features a comfortable bed, private kitchenette, en-suite hot shower, dedicated workstation, and high-speed fiber Wi-Fi.
2. **Studio (2 Guests):** Spacious executive living for couples or colleagues. Features a king bed, private kitchenette, cozy sitting & dining nook, hot shower, and daily servicing.
3. **Penthouse (2–3 Guests):** Our crowning residence with panoramic African sunrise and sunset views. Features a king bed, expansive furnished lounge, private kitchenette, en-suite bathroom with hot shower, and complimentary airport pickup.

---

## 🍽️ Amenities & Social Spaces

* **Megg's Lounge & The Ivy:** Artisanal Kenyan tea & coffee, afternoon teas, book reading library, custom dining with fresh Kisumu market ingredients.
* **Fresh Continental Breakfast:** Available daily on order at an extra fee.
* **Kisumu 50+ Gala Events:** Micro & macro event hosting, private celebrations, outside catering on a budget.
* **Business Travel Hub:** High-speed Wi-Fi, printing, scanning, and secretarial support.

---

## 📦 Installed Dependencies

* **Framework:** Next.js `16.4.2` + React `19.3.0` + TypeScript `5`
* **Styling:** Tailwind CSS `v4` with PostCSS (`@tailwindcss/postcss`, `postcss`)
* **Icons:** `lucide-react`
* **Utilities:** `clsx`, `tailwind-merge`
* **Compilation Support:** `lightningcss-win32-x64-msvc`

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
